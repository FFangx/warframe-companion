# Warframe Companion Desktop

Electron/React 桌面应用默认打开总览与右侧助手，左侧默认仅有总览，默认缩成图标栏，顶部 ‹ / › 可展开或收起；“添加功能”支持固定和取消固定市场。右上角的全局助手可收起或放大，窄窗口切换显示。导航展开、市场固定和助手开关通过本机 localStorage 记住，查询与会话仍仅保留在内存。总览提供市场快捷查询、掉落查询示例与本次行情记录；活动、周常和个人数据仍待接入。

总览中的市场快捷查询要求显式输入物品、平台、跨平台开关与等级，通过安全 preload IPC 调用真实只读 `market-query-service`。结果分别展示当前买卖挂单、90 日已成交统计、证据时间、来源、警告、空订单和分类故障；不会下单、挂单或发送交易私聊。

完整行情卡在订单快照内提供分页、买卖方向与在线状态筛选，显示快照总数、筛选后数量与分页位置；卖单行显示卖家信誉与等级（仅可升级物品），当前卖价相对 90 日成交中位的偏离与历史口径分开标注。仅卖单可预览购买私聊文本（按卖家语言生成的 `/w` 目标、物品规范名、等级、单价、模板语言与文本），复制只写本机剪贴板、绝不自动发送聊天或交易。翻页、筛选、预览与复制直接消费已校验结果，不调用模型、不重复查询市场。主进程持有自己产出的行情快照，执行预览/复制时按快照 id 与订单下标核验可信快照、所选订单和过期时间，renderer 无法自报卖家、价格、语言或时间来伪造可信订单；复制失败会明确反馈。结果过期（含预览后过期）会拒绝复制并显示刷新入口，刷新保持原查询范围，清除旧订单选择并要求重新选择。订单身份、卖家语言与私聊文本只进入桌面会话的展示通道，不进入模型消息、AgentTrace、日志或评估。

行情卡同时展示物品图（仅 Warframe.Market 静态 https 资源，加载失败本地隐藏）、MOD/赋能词条效果行、杜卡德与按等级换算的传说赋能交易税，以及套装查询的散件单价×数量与“散件合计 vs 整套最低”比较：缺报价部件标为“无卖单”并计入“缺 N 件报价”，散件全部无报价时显示“散件均无在线报价”，从不伪造合计；统计、图片、词条或散件报价失败都只降级对应区块，不把有效的当前订单快照判为失败。

助手使用 `@warframe-companion/agent-runtime`。用户可在设置弹窗中选择本地离线 profile，或保存 OpenAI-compatible 本机 profile，查看能力与健康状态，再沿“可信策略 → 模型 adapter → 工具调用 → 工具结果 → 证据回答 → `AgentTrace`”运行；支持 `market.query` 与 `drops.search`、停止、由主进程构造的默认运行策略（120 秒硬截止、15 次工具、24 次模型请求并预留 1 次最终汇总；renderer 不能提高预算）与取消贯穿（健康检查、模型请求、领域工具共享同一 AbortSignal）。模型配置位于 Electron `userData/config/model-profiles.v1.json`，只含凭据环境变量引用，不含 key；掉落数据位于 `userData/public-data`。支持工具结果回送的 adapter 已能接收脱敏摘要并生成后续回答，第 15 次观察后有一次受限最终汇总（finalize 模式不暴露业务工具；失败/非法/超时只做一次程序收束）。当前没有接入视觉、模型 fallback、OpenClaw/DeepSeek 桌面 backend、个人快照或订阅写入；真实远程模型桌面试用尚未完成。

Agent 对话使用 `MarketResultCard` 摘要，保留价格、范围、来源与时间；点击后在主工作区展开同一快照的完整订单与统计，不触发重复查询。快捷查询也复用完整卡片。查询失败可重试；名称有候选时可选择并发送新查询。行情展示数据只保留在桌面会话中，不加入模型或执行轨迹。已打开的页面在切换时保留，因此查询可以在其他页面打开期间完成，返回后仍能查看或停止；关闭应用不保留会话历史。

自然问价（如“母牛p多少钱”）由主进程按本机保存的默认交易范围补全平台与跨平台；等级缺省按规则：Prime 简称默认整套、明确部件查部件、可升级物品默认 0 级、“满级”由物品元数据求值、套装等不适用等级的条目不要求等级。首次缺少保存范围时只出现一次可点击选择卡（推荐 PC 跨平台），选择后保存为永久偏好并继续原查询，之后每次查询与应用重启沿用，可在设置修改；单次查询里明确给出的平台/跨平台只覆盖当次请求，不会改动保存值。偏好保存在 `userData/config/market-scope-preference.v1.json`，路径由主进程固定，renderer 仅通过类型化 IPC 读取或显式保存；未配置/损坏文件不会被读取方覆盖。

当前按现有助手的功能对照表搭建桌面原型。D1a、D1b（分页、筛选、私聊预览与显式复制、过期门禁）、D2b0 一次配置自然问价、D1c 市场模板对齐与 D2a1 循环预算/停止均已完成主管验收；D2a1 的 RunPolicy、一次受限最终汇总、统一取消/超时与一次终态已通过 164 项合成根测试、桌面打包及 40/40 可见合成 Electron 回归。真实 Warframe.Market 与真实远程模型预算仍未验证；下一步 D2a2 证据与协议，之后逐项接掉落/遗物、世界状态/周常/商店、个人数据与决策、愿望单/订阅。入口与模型体验随功能改善。安装发布与跨仓库重构不作为前置，见 [开发计划](../../docs/DEVELOPMENT_PLAN.md)。

## 开发

```powershell
npm run start -w @warframe-companion/desktop
npm run build -w @warframe-companion/desktop
```

设置 → 连接与诊断默认探测 `127.0.0.1:18789` 的 OpenClaw Gateway 和 Warframe.Market 公共接口。WFInfo 与 AlecaFrame 不猜测本机安装路径，可通过以下环境变量显式配置：

- `WARFRAME_COMPANION_WFINFO_EXE`
- `WARFRAME_COMPANION_ALECAFRAME_DIR`
- `WARFRAME_COMPANION_OPENCLAW_HOST`
- `WARFRAME_COMPANION_OPENCLAW_PORT`
- `WARFRAME_COMPANION_BUILD_ID`

所有探针、市场查询与 Agent 工具均只读；renderer 仅能通过 preload 暴露的类型化 IPC 读取/保存本机 profile、检查模型、运行 Agent 和取消，未启用 Node 集成。Base URL 必须是 HTTPS 或本机回环 HTTP；界面只接受环境变量名，绝不接受 key 值。
