# 桌面视觉试版：轨道器工作台

2026-09-04，使用 frontend-design 指导本轮视觉设计；只改变呈现，保留可折叠导航、固定入口、主工作区与全局助手。

## 设计选择

- 底色石墨灰 `#191b1e`，导航 `#141619`，内容面 `#23262a`，分隔线 `#363a3f`，正文 `#eeeef0`，强调色哑金 `#d5bb83`。
- 中文优先使用系统 Microsoft YaHei UI，西文使用 Segoe UI；标题 25–34px，正文 13–14px，辅助文字 11–12px。无需联网下载字体。
- 总览左对齐，查询入口并列、记录纵向展开；助手标题、示例和输入保持独立层次。轨道图形作为唯一主要装饰，采用仓库内 SVG。
- 主导航、查询入口与助手使用 Phosphor Regular 图标，选中导航与已展开助手使用 Fill。克制使用描边，不再让每个区域都带青色发光效果。

## 结构与自审

```text
折叠导航 | 品牌                                      全局助手
         | 总览标题 / 轨道图形               | 助手
         | 市场入口    掉落入口              | 解释和示例
         | 最近查看                          | 对话记录
         |                                   | 输入框
```

本轮没有改为通用营销首页，也不制作虚假的推荐卡。初版截图发现查询入口堆叠导致空总览需要滚动，因此保留并排入口并减少标题区高度。市场完整详情、高级设置及诊断已在后续全流程设计中统一，见下文。D1b 继续负责订单分页、筛选与复制等新功能。

样式入口为 `workbench.css`，覆盖全部现有功能与状态；`styles.css` 保留工作区结构与布局，旧市场和配置组件的蓝色视觉层已移除。

验证：开发打包、根级 85 项测试及 Electron 合成交互检查；覆盖折叠/固定功能、查询不抢占主区、助手放大与还原、重启偏好和 900px 窗口。未涉及真实模型费用、个人数据或生产运行时。

## 图标规范

2026-09-04 接入 `@phosphor-icons/react` 2.1.10（MIT），保留[许可文本](../licenses/PHOSPHOR-ICONS.txt)。按单图标模块导入，图标随应用打包，无需联网获取。

| 含义 | 图标 |
|---|---|
| 总览 | SquaresFour |
| 市场 | Tag |
| 掉落地点 | MapPin |
| 助手 | ChatCircleDots |
| 设置 | GearSix |
| 最近查看 | ClockCounterClockwise |

默认 20px，示例行 16px，助手空态 26px；颜色继承所在控件。折叠导航保留名称提示和可访问名称，SVG 自身不重复朗读。品牌标志与轨道图形保留自绘 SVG，不与助手图标混用。刷新、搜索、展开箭头同属 Phosphor。

桌面由 Vite 打包，类型检查使用 ESNext/Bundler 解析以兼容图标库声明；共享 Node packages 配置不变，不启用 skipLibCheck。
## 全流程设计与微动效

2026-09-04 使用 Impeccable 4.1.3 的 polish、animate、craft-floor 扩展已认可的视觉方向。

- 范围：总览、折叠导航、常用功能选择、助手空态/对话/执行轨迹、行情摘要、直接查询表单、加载、完整行情、无订单、错误、物品候选、模型配置与诊断。
- 行情优先显示最低卖价和最高买价，再展示成交统计、买卖订单及证据；统计不可用不掩盖当前订单成功。
- 正文和表单 13px，辅助信息 11–12px；订单数值对齐，长名称与诊断来源换行。字段标签置于输入框上方。
- 重新查询保留上次结果及其原查询范围，加载文案明确说明；新结果抵达后同时替换数据与范围。
- 配置保存与删除具备进行中、成功、失败状态；保存期间禁用编辑，失败保留填写内容。设置标题与关闭按钮在滚动时保持可见。
- 控件颜色反馈 120ms；导航/助手网格变化 200ms；弹窗进入 200ms、退出 100ms；结果首次出现 180ms。查询期间使用局部转圈，无额外动效依赖。
- 系统减少动态效果偏好关闭位移、旋转和布局动画，保留明确文字反馈；弹窗保留原生焦点管理和 Escape 关闭。

验收：根级 85 项测试、桌面打包；Electron 合成数据验证市场初始/加载/成功/空订单/失败、模型保存、诊断、Escape、900px 布局与减少动态效果；无渲染异常。既有导航/固定功能/重启偏好/助手不抢占工作区回归通过。Impeccable 静态检测返回空问题列表，桌面和窄窗截图两轮检查完成。合成图片只用于设计验收，不代表实际行情或真实模型连通性。

本轮不扩展 D1b、D3–D6 功能，也不把公共情报或个人推荐标记为已实现。
