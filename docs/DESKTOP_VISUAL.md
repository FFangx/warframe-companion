# 桌面视觉试版：轨道器工作台

2026-09-04，使用 frontend-design 指导本轮视觉设计；只改变呈现，保留可折叠导航、固定入口、主工作区与全局助手。

## 设计选择

- 底色石墨灰 `#191b1e`，导航 `#141619`，内容面 `#23262a`，分隔线 `#363a3f`，正文 `#eeeef0`，强调色哑金 `#d5bb83`。
- 中文优先使用系统 Microsoft YaHei UI，西文使用 Segoe UI；标题 25–34px，正文 13–14px，辅助文字 11–12px。无需联网下载字体。
- 总览左对齐，查询入口并列、记录纵向展开；助手标题、示例和输入保持独立层次。轨道图形作为唯一主要装饰，采用仓库内 SVG。
- 主导航、查询入口与助手使用 Phosphor Regular 图标，选中导航与已展开助手使用 Fill。克制使用描边，不再让每个区域都带青色发光效果。

## 结构与自审

```text
折叠导航 | 品牌                                      全局助手
         | 总览标题 / 轨道图形               | 助手
         | 市场入口    掉落入口              | 解释和示例
         | 最近查看                          | 对话记录
         |                                   | 输入框
```

本轮没有改为通用营销首页，也不制作虚假的推荐卡。初版截图发现查询入口堆叠导致空总览需要滚动，因此保留并排入口并减少标题区高度。市场完整详情和高级设置仍沿用既有结构，后续随 D1b 改善。

样式入口为 `workbench.css`，在旧功能样式后加载，限定本轮界面与共享对话卡的视觉调整；后续推广时逐组件迁移旧规则，避免继续堆叠局部覆盖。

验证：开发打包、根级 85 项测试及 Electron 合成交互检查；覆盖折叠/固定功能、查询不抢占主区、助手放大与还原、重启偏好和 900px 窗口。未涉及真实模型费用、个人数据或生产运行时。

## 图标规范

2026-09-04 接入 `@phosphor-icons/react` 2.1.10（MIT），保留[许可文本](../licenses/PHOSPHOR-ICONS.txt)。按单图标模块导入，图标随应用打包，无需联网获取。

| 含义 | 图标 |
|---|---|
| 总览 | SquaresFour |
| 市场 | Tag |
| 掉落地点 | MapPin |
| 助手 | ChatCircleDots |
| 设置 | GearSix |
| 最近查看 | ClockCounterClockwise |

默认 20px，示例行 16px，助手空态 26px；颜色继承所在控件。折叠导航保留名称提示和可访问名称，SVG 自身不重复朗读。品牌标志与轨道图形保留自绘 SVG，不与助手图标混用。刷新、搜索、展开箭头同属 Phosphor。

桌面由 Vite 打包，类型检查使用 ESNext/Bundler 解析以兼容图标库声明；共享 Node packages 配置不变，不启用 skipLibCheck。
