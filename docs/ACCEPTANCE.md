# 验收分层

Warframe Companion 的“完成”必须说明证据所在层级；低层通过不能替代高层验收。

| 层级 | 必需证据 | 不能声称 |
|---|---|---|
| 源码 | `npm run check:repo`、build、test、确定性 eval 与生产依赖审计通过 | GitHub CI 已通过 |
| CI | 固定提交的 Windows / Node 22 检查全绿 | Windows 安装包可用 |
| 打包 | `electron-forge make`、制品身份、安装/启动/升级/卸载与恢复验证 | 真实数据链全部可用 |
| 实机 | 健康页、真实只读查询、来源/时间、故障降级与隐私边界验证 | 未迁移功能已经交付 |

## 当前公开状态

仓库当前只承诺源码与 CI 层。尚未发布经过打包和实机验收的 Windows 安装包。

## 每次变更的最低要求

1. 固定基线提交，声明目标、非目标以及是否触及运行时、个人数据或外部渠道。
2. 正常、空结果、来源故障、过龄/缓存、权限负例和取消/超时按风险覆盖。
3. 测试与评估仅使用合成或脱敏数据。
4. 源码、CI、打包、实机、推送与发布状态分别报告。
5. 状态型迁移必须证明单写者、备份、幂等、崩溃恢复和可回滚，且不得删除用户数据。
