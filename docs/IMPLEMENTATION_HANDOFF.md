## 首张新代码单可直接派发的内容

目标是消除“问价前填参数”的负担。先读当前规则与上述三份合同、检查工作树；保留已有 D1b 候选。仅修改市场范围偏好、实体/等级补全、一次选择界面和相关测试；不实现整个状态机、历史存储、其他游戏模块或生产迁移。落点限现有 market/runtime 参数入口、desktop main/preload/settings/选择卡及其必要类型；新增模块放在现有包内，不另建框架。

用合成配置证明：已配置PC的整套问价没有clarify；无配置只出现一次可点击选择，完成后继续原查询并在下一次/重启沿用；rank=0/max/不适用/越界分别正确；别名多候选显示具体物品；IPC不信任renderer权限和任意路径。不得以删掉必要工具参数校验来通过；不得在模型提示词硬编码当前用户个人身份。先交小范围diff和测试输出，缺条件给具体阻塞证据，不自动扩大工单。

## Flash 模型验证

设计阶段本轮不发起新的远程调用。后续在已授权的 OpenClaw `agent` 路径可以测试公开/合成问题，先读取其运行规则并核实实际模型；不改配置、不私聊、不投递QQ。候选集：简称问价、满级追问、否定旧条件、多实体指代、价格+获取组合、源失败、可选追问、模糊图片识别。每场景至少3次，保留实际模型/profile版本、目标覆盖、参数/证据错误、不必要澄清、首次有用结果/总耗时、调用数及usage来源。相同模型再走 Companion adapter/桌面流程，不能拿旧线通过代替新线通过。

关键边界（未授权写入、伪造状态、丢失明确纠正）在验收样例必须零违规；语义与延迟逐例报告，失败复现后收窄工具/调整上下文再测，不用更强模型替考。不把少量样例成功包装为95%总体可靠率。私聊身份场景只能用合成合同回归，真实渠道仍标未验收。

## 主管检查与停止点

worker 无权提交/推送/部署；同一工作树只有一个代码写入者。启动前读取 deepseek-worker 技能，确认没有遗留worker，记录允许文件/当前diff；超时只表示进程状态，主管检查实际产物，先缩小剩余工单，不重复开大任务。根 `npm test` 与相关构建/模型评估/真实Electron流程按切片执行，报告合成与真实边界；禁止重复上次用错测试入口弹出主进程错误的做法。

设计收口完成 ≠ 所有功能设计过实机 ≠ 已实现。开始下一代码任务前无需再做通用产品问卷；若遇新的游戏语义歧义，先核对原模板/源码。远期每个功能派发时补该模块字段级合同及合成样例，属于工单细化，不改变本合同。当前 D2a1 已完成主管验收；D2a2 证据与协议尚未派发。
