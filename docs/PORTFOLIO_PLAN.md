# Agent 工程作品集计划

> 目标岗位：Agent Systems Engineer / Applied AI Engineer / AI Product Engineer

## 项目要证明的能力

这个项目不以“支持多少 Warframe 命令”为主要卖点，而要提供以下可验证证据：

1. 能把自然语言 Agent 与确定性工具正确分层。
2. 能设计模型无关的工具契约、证据协议和渠道适配器。
3. 能处理可信身份、个人数据和高风险工具边界。
4. 能对多轮工具 Agent 建立评估集、轨迹指标和回归门禁。
5. 能排查数据源、调度、投递、部署和运行时漂移等生产故障。
6. 能把原型交付成可安装、有诊断、有升级路径的桌面产品。

## 最终公开交付物

- 一个脱敏、可复现构建的公开仓库。
- 一个可下载的 Windows 安装包。
- 一段不超过三分钟的产品演示。
- 产品定义、架构图、安全边界和数据流说明。
- 覆盖已交付工具、真实故障、权限负例和降级路径的脱敏 Agent eval，以及可重复运行的报告；以风险覆盖率而非固定条数验收。
- OpenClaw 与另一 Harness/模型的同契约对比实验。
- 至少两篇技术文章和三篇简短故障复盘。
- CI 中可复现的核心测试、评估抽样和发布检查。

## 公开与私有边界

### 可以公开

- 类型化工具契约和合成/脱敏测试夹具。
- 数据源适配逻辑、证据协议、Agent 适配器和桌面 UI。
- 不包含个人信息的故障复盘、架构决策和评估报告。
- 自动测试、mock 服务和可重复演示。

### 必须保持私有

- API Key、Market Token、QQ 号、账号标识和允许名单。
- AlecaFrame 解密密钥、原始快照、物品实例 ID 和个人交易数据。
- 含真实聊天对象或真实个人消息的日志与截图。
- 任何可用于操作游戏、交易、聊天或账号资产的能力。

## 作品集里程碑

### P1：可安装的确定性桌面切片

- Windows 桌面壳能够诊断本地组件。
- `market.query` 通过真实数据和 mock 数据测试。
- `wm 古纪V3` 以 React 原生卡片展示。
- 发布一个带构建身份的预览安装包。

### P2：可度量的 Agent

- 桌面端能够通过 Agent 调用同一工具契约。
- 已建立 41 条合成/脱敏评估（30 条原始用例、8 条 `drops.search` 与 3 条 `account.snapshot`）、确定性 runner、参考契约基线与桌面 Harness 轨迹；后续按新增工具、真实故障和权限边界扩展，不以凑固定数量代替风险覆盖。
- 报告工具选择、事实正确、证据合规、越权阻断、故障降级、延迟和调用次数。

### P3：跨 Harness 实验

- 为 DeepSeek Harness 编写隔离适配器或插件。
- 使用相同评估集对比 OpenClaw 与 DeepSeek Harness。
- 记录迁移成本、兼容性、可靠性和框架锁定风险，而不是只展示“成功运行”。

### P4：公开作品集

- 完成脱敏审计、README、演示视频和架构说明。
- 发布 Windows Preview。
- 整理可用于简历和面试的量化结果与五个故障故事。

## 暂定简历表述

以下句子只能在对应证据公开后使用，数字必须由自动报告产生：

- 独立设计并实现本地优先的工具型 AI Agent，将自然语言路由与确定性实时数据工具结合，并交付为 Windows 桌面应用。
- 设计带范围、时间和新鲜度的证据协议，防止模型将静态资料、历史记录和过期快照误述为当前事实。
- 实现可信会话鉴权和工具执行门禁，隔离公开查询与个人数据，并以自动化负测验证越权阻断。
- 建立可验证部署与 Agent eval 流程，以统一数据集衡量工具选择、证据合规、故障降级和跨 Harness 表现。
