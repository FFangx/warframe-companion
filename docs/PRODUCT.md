# Warframe Companion Agent 产品定义

> 状态：桌面原型优先，2026-09-03 修订

## 一句话定位

一个 Windows 本地优先、以只读和可验证为原则的 Warframe 国际服个人 Agent 主机：把实时情报、市场查询、个人快照、订阅提醒和 WFInfo 奖励决策整合为一个可安装的软件；QQ/OpenClaw 是现有远程入口，后续可通过受控 Channel Adapter 增加飞书、微信或其他社媒频道。

## 当前用户与场景

- 第一阶段只服务项目所有者本人，不建设多用户 SaaS。
- 主要入口是 Windows 桌面应用；现阶段 QQ 用于离开电脑时查询和接收提醒，后续远程频道按同一合同逐个接入。
- 远程频道是本地 Agent 的可选入口，不是独立业务实现；新增频道必须复用同一身份、权限、事实、Outbox 和降级合同。
- 用户打开软件后无需记忆命令，也能看到关键轮换、最近提醒和常用查询；系统健康放在设置中的诊断入口。
- 自然语言负责理解和解释；实时数据、个人数据和状态性结论必须来自确定性工具及匹配范围的新鲜证据。

## 当前原型范围

以现有 OpenClaw 助手能力为对齐目标，从市场完整流程起步，逐项做成可连续使用的桌面功能：

- 左侧导航默认仅有总览，默认缩为图标栏，使用 ‹ / › 展开或收起；玩家可固定已完成的功能入口，当前可固定市场。导航状态和固定项保存在本机。
- 助手位于右上角，是所有功能共用的对话面板，独立开关并记住状态；可临时放大，窄窗口切换显示。对话不占左侧导航，也不会因查询完成自动替换中间内容。
- 对话使用简洁行情摘要，完整订单在主工作区展开；共享结果组件逐步补齐筛选、分页、私聊文本预览与显式复制。
- 切换页面保留本次会话与结果；查询、加载、停止和失败后重试清楚可见。
- 模型配置放到适当位置，主界面突出查询与结果，按实际模型显示离线/远程状态。
- 掉落结果可浏览，显示地点、概率、来源和数据时间。
- 接遗物正反查与获取路线，再接世界状态/裂缝、周常、赏金、商店与轮换。
- 随后接本机库存与个人决策、周常记录、愿望单和订阅提醒；每项有明确桌面入口与适用的 Agent 查询/操作。

开发启动即可试用。功能对齐从当前主线开始，界面优化随各功能推进；安装包、跨仓库共享核心和多频道接入按实际需求后移。对照表与执行顺序见 [`DEVELOPMENT_PLAN.md`](DEVELOPMENT_PLAN.md)。

## 总览推荐的后续方向

先在总览提供基于公共游戏数据的当前情报和关注项命中，再结合本机目标、库存、完成记录做少量规则驱动的个人建议。建议显示原因、来源与时间，并支持忽略；模型负责解释，不预先建设偏好学习或综合评分系统。公共情报随 D4 接入，个人建议随 D5 接入，不作为导航或功能对齐的前置。功能按市场、遗物、周常等任务组织，多个操作共用同一功能界面。

## 产品完整方向

以下按功能对齐顺序分批落地，不要求在首个市场切片中全部完成：

- 显示 OpenClaw、WFInfo、AlecaFrame、数据源和运行构建状态。
- 通过桌面界面调用既有公开查询，并显示结构化结果、来源和数据时间。
- 在 Agent 对话和按需展开的详情区中使用同一套原生结果组件：支持分页、筛选、展开证据，以及由用户明确触发的安全本地动作；例如预览并复制购买私聊文本，但绝不自动发送聊天或执行交易。
- 通过 Companion 现有 Agent Harness 和类型化服务提供对话入口，后续按实际复用需要抽取跨宿主共享核心。
- 提供 Warframe 专用 Agent Harness：用户可选择主 Agent 模型 profile，系统显式检查工具、结构化输出、视觉、流式、取消和上下文能力，不把单一 provider 设为产品中心。
- 查看现有个人快照、周常与订阅；所有个人数据继续本机处理。
- 查看提醒记录与投递诊断，不以单一成功标志代替端到端证据。
- 提供统一诊断入口，能够区分源码、部署、运行时、数据源和渠道故障。

## 明确不做

- 不自动登录或操作 Warframe 客户端。
- 不制作挂机、宏或游戏内自动化。
- 不自动交易、挂单、改单、聊天或操作账号资产。
- 不上传 AlecaFrame 原始快照、账号标识、令牌或解密密钥。
- 不在第一版建设账号系统、云同步、多人协作、插件市场、移动端或商业计费。
- 原型每次只推进一个用户流程，新增业务场景依据试用反馈选择。

## 产品原则

1. **本地优先**：个人数据、凭据和游戏集成默认留在本机。
2. **确定性优先**：能由结构化工具完成的任务，不让模型凭记忆猜测。
3. **证据优先**：状态性结论必须携带对象、范围、时间、新鲜度和来源。
4. **最小权限**：身份由可信运行时上下文提供，模型不能自行声明授权。
5. **可降级**：模型、公共数据源、QQ 或 WFInfo 不可用时，软件应说明影响范围并保留可用能力。
6. **可验证发布**：发布物必须能追溯到源码提交和内容哈希，并通过统一验证。
7. **渠道复用**：桌面端和 QQ 共用业务工具，分别采用原生 UI 与图片/文字呈现。
8. **模型可替换**：模型由 profile 配置，Harness 与类型化 Warframe 工具属于 Companion；不兼容模型明确降级，不伪装能力。
9. **交互不经模型**：翻页、筛选、复制和展开等界面动作直接消费已校验的结构化结果，不把模型文本反向解析成命令或事实。
10. **频道可替换**：Agent 拥有统一 Channel Adapter 与本地绑定合同；每个频道只处理连接、身份、能力与呈现，不拥有 Warframe 业务逻辑。

## 当前里程碑：可试用的桌面原型

首个可试用流程通过开发启动的 Windows 应用，能够：

1. 从明确的查询入口完成一次真实只读市场查询，并在 Agent 中直接使用行情卡。
2. 切换页面后保留当前会话与结果，能筛选订单、预览和复制购买私聊文本。
3. 在行情中看清来源、时间与查询范围。
4. 清楚显示所选模型与运行状态；数据源或模型失败时能理解原因并重试。

随后立即按开发计划的功能对照表推进掉落/遗物、世界情报、个人数据和提醒，逐项记录“部分可用 / 已对齐”，不等待全面 UI 美化。真实远程模型另记录试用结果，未配置时本地规则仍可用于原型验证。需要对外分发时再完成安装与发布里程碑。
